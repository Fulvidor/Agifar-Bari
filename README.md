# Archivio contenuti di Agifar BAT

Questa cartella contiene i contenuti che il sito legge ogni volta che viene aperto:

- `contenuti.xlsx`: eventi, corsi, convenzioni, notizie, organigramma, galleria, trasparenza e informazioni
- `immagini/`: locandine, foto dell'organigramma e della galleria
- `documenti/`: i PDF della sezione Trasparenza

## Come si aggiorna

1. Modifica `contenuti.xlsx` sul tuo computer e controllalo con la pagina «controlla-excel».
2. Su questa pagina clicca **Add file**, poi **Upload files**, e trascina il file con lo stesso nome (e le eventuali nuove immagini o documenti, dentro la rispettiva cartella).
3. Clicca **Commit changes**. Entro cinque minuti il sito mostra le novità.

Non rinominare file e cartelle: il sito li cerca con questi nomi.
